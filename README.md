# remember

用語を選んで、その用語に関する4択（一部3択）問題を順番に解いていくクイズゲームです。

**遊ぶ：** https://lumiere2110.github.io/remember/

## 遊び方

1. 上のURLを開く（またはローカルの `index.html` をダブルクリック）
2. ジャンル → カテゴリ → 用語 の順に選ぶ。上の検索欄で用語名から探すこともできる
3. 出題の設定をしてスタート
   - **出題する問題**：すべて／タグを付けた問題だけ
   - **難易度**：Lv.1〜Lv.4 から複数選べる（下の表）
   - **回答時間**：制限なし / 10・20・30・60秒 / 自由入力（秒）。時間切れは不正解
   - **問題数**：全問 または 好きな数
   - **出題順**：登録順 / ランダム
   - 選択肢（ア〜エ、3択の問題はア〜ウ）の並びは毎回ランダム
4. 回答すると、正解の解説と選択肢ごとの正誤の理由、用語の解説が表示される
5. 結果画面で振り返り。間違えた問題だけ解き直すこともできる

キーボードの `1`〜`4` または `A`〜`D` でもア〜エを選べます。

## 難易度

| レベル | 目安 |
|---|---|
| Lv.1 | ITパスポート試験で出そうなレベル |
| Lv.2 | 基本情報技術者試験で出そうなレベル |
| Lv.3 | 応用情報技術者試験で出そうなレベル |
| Lv.4 | それらよりかなり難しいレベル |

## タグ・お気に入り

問題を解いているときや結果画面で、問題に ★お気に入り・#復習 や自分で作ったタグを付けられます。

ホームの「タグ」からタグを選ぶと、タグの管理画面が開きます。

- 入っている問題の一覧を見る・タグから外す
- 「問題を追加する」から、問題文や用語名で探してタグに追加する
- タグに入っている問題を、用語をまたいでまとめて解く
- 自分で作ったタグの名前の変更・削除（お気に入り・復習は変更・削除できない）

ホームの一番下から、新しいタグを作ることもできます。

タグと設定はブラウザに保存されます（端末・ブラウザごとに別々）。

## 用語と問題の追加

`data/terms.js` の `TERMS` 配列に追加します。ジャンル・カテゴリは用語に書いた名前から自動で作られます。

```js
window.TERMS = [
  {
    genre: "情報・テクノロジー",
    category: "ネットワーク",
    name: "用語名",
    description: "一覧に出る短い説明（任意）",
    explanation: "用語の解説（任意）",
    questions: [
      {
        question: "問題文",
        choices: ["選択肢ア", "選択肢イ", "選択肢ウ", "選択肢エ"], // 4つ（3択なら3つ）
        answer: 0,               // 正解の番号（0=ア〜3=エ）
        level: 1,                // 難易度 1〜4
        explanation: "正解の解説（任意）",
        choiceExplanations: [    // 選択肢ごとの解説（任意）
          "アが正しい理由", "イが誤りの理由", "ウが誤りの理由", "エが誤りの理由",
        ],
        tags: ["頻出"],          // 最初から付けるタグ（任意）
      },
    ],
  },
];
```

同じ問題を複数の用語に入れたいときは、`terms.js` 上部の `SHARED` に一度だけ書き、各用語の `questions` に `SHARED.名前` で入れます。
付けたタグはどの用語から解いても共通です。

用語がまだないジャンル・カテゴリを先に作るときは、`terms.js` の `CATEGORIES` に書きます。

```js
window.CATEGORIES = [
  { genre: "物理", categories: ["電気・電子"] },
];
```

選択肢は4つ（4択）か3つ（3択）。それ以外の数の問題や `answer` が範囲外の問題は出題されません。
