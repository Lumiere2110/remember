# remember

用語を選んで、その用語に関する4択問題を順番に解いていくクイズゲームです。

**遊ぶ：** https://lumiere2110.github.io/remember/

## 遊び方

1. 上のURLを開く（またはローカルの `index.html` をダブルクリック）
2. ジャンル → カテゴリ → 用語 の順に選ぶ。上の検索欄で用語名から探すこともできる
3. 出題の設定をしてスタート
   - **出題する問題**：すべて／タグを付けた問題だけ
   - **回答時間**：制限なし / 10・20・30・60秒 / 自由入力（秒）。時間切れは不正解
   - **問題数**：全問 または 好きな数
   - **出題順**：登録順 / ランダム
   - **選択肢のシャッフル**：ア〜エの並びを毎回入れ替える
4. 回答すると、正解の解説と選択肢ごとの正誤の理由、用語の解説が表示される
5. 結果画面で振り返り。間違えた問題だけ解き直すこともできる

キーボードの `1`〜`4` または `A`〜`D` でもア〜エを選べます。

## タグ・お気に入り

問題を解いているときや結果画面で、問題に ★お気に入り や好きなタグ（例：苦手、復習）を付けられます。
付けたタグはホームの「タグから解く」から、用語をまたいでまとめて解けます。

タグと設定はブラウザに保存されます（端末・ブラウザごとに別々）。

## 用語と問題の追加

`data/terms.js` の `TERMS` 配列に追加します。ジャンル・カテゴリは用語に書いた名前から自動で作られます。

```js
window.TERMS = [
  {
    genre: "情報・テクノロジー",
    category: "ネットワーク",
    name: "用語名",
    description: "一覧に出る短い説明（任意）",
    explanation: "用語の解説（任意）",
    questions: [
      {
        question: "問題文",
        choices: ["選択肢ア", "選択肢イ", "選択肢ウ", "選択肢エ"], // 必ず4つ
        answer: 0,               // 正解の番号（0=ア〜3=エ）
        explanation: "正解の解説（任意）",
        choiceExplanations: [    // 選択肢ごとの解説（任意）
          "アが正しい理由", "イが誤りの理由", "ウが誤りの理由", "エが誤りの理由",
        ],
        tags: ["頻出"],          // 最初から付けるタグ（任意）
      },
    ],
  },
];
```

選択肢が4つでない問題や `answer` が範囲外の問題は出題されません。
