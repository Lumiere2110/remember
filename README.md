# remember

用語を選んで、その用語に関する4択問題を順番に解いていくクイズゲームです。

## 遊び方

1. `index.html` をブラウザで開く（ダブルクリックでOK）
2. ジャンル → カテゴリ → 用語 の順に選ぶ
3. 出題の設定をしてスタート
   - **回答時間**：制限なし / 10・20・30・60秒 / 自由入力（秒）。時間切れは不正解
   - **問題数**：全問 または 好きな数
   - **出題順**：登録順 / ランダム
   - **選択肢のシャッフル**：A〜Dの並びを毎回入れ替える
4. 結果画面で振り返り。間違えた問題だけ解き直すこともできる

キーボードの `1`〜`4` または `A`〜`D` でも回答できます。設定はブラウザに保存されます。

## ジャンル・カテゴリ

`data/genres.js` で定義しています。

## 用語と問題の追加

`data/terms.js` の `TERMS` 配列に追加します。

```js
window.TERMS = [
  {
    genre: "it",            // genres.js のジャンル id
    category: "network",    // genres.js のカテゴリ id
    name: "用語名",
    description: "用語の説明（任意）",
    questions: [
      {
        question: "問題文",
        choices: ["選択肢A", "選択肢B", "選択肢C", "選択肢D"], // 必ず4つ
        answer: 0,               // 正解の番号（0〜3）
        explanation: "解説（任意）",
      },
    ],
  },
];
```

選択肢が4つでない問題や `answer` が範囲外の問題は出題されません。
